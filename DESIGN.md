# Orbit — активный native дизайн

2026-10-12: SwiftUI iOS/macOS, русский интерфейс. Прежний веб-дизайн docs/web-baseline-2026-10-12/DESIGN.md сохранён как reference, не шаблон обязательного пиксельного переноса.

## Первый экран

Inbox: заголовок «Входящие», короткое поле «Название задачи» и действие «Добавить», Enter добавляет. Пустой state честный, без seed данных по умолчанию. Строка: текст + независимый control завершения; завершённые задачи доступны для reopen. Обе группы можно показать простыми секциями, без панели фильтров в первом TASK. После save input очищается, после failure draft остаётся и ошибка видна. SwiftUI native controls, Dynamic Type/accessibility labels, клавиатура и системная тема.

На Mac — нормальное окно с рабочим клавиатурным вводом; не строить сразу большой sidebar из пустых маршрутов. На iPhone позже — компактный native список с safe areas; адаптация target/nav отдельная задача. Никаких экранов логина, предупреждений о сервере или фальшивых счётчиков/синхронизации.

Следующие screens только по отдельным assignments: Projects, Today/Upcoming, task editing. Не переносить технические storage/sync подробности в основной пользовательский flow; ошибка сохранения должна быть понятной и не скрывать потерю записи.

## Актуальное направление iPhone, 2026-10-13

Пользователю нравится визуальный стиль интерактивного концепта: системная типографика, спокойные поверхности, тонкие разделители, круглое завершение, один coral accent; нативный Liquid Glass для нижней навигации и действия добавления при поддержке системой. Следующие задания должны сохранять это направление, а не повторять примитивный macOS prototype UI.

Нижние вкладки: Сегодня · Входящие · Предстоящее; Проекты только после отдельной реализации. Отдельного пункта «Календарь» нет (актуальная инструкция2026-10-14). Сегодня и Предстоящее: переключатель Список/Календарь внутри раздела. Масштабы календарного представления Предстоящего: День/3 дня/Месяц. Неделя удалена по прямому запросу. 3 дня строятся точно по принципу Дня: три полных временных колонки с общей шкалой, блоки задач в своих интервалах и отдельная область для задач без времени. Полный диапазон суток должен быть доступен в настоящем приложении;9–20 в макете — демонстрационный диапазон, не ограничение модели задач. Месяц — сетка дат и задачи выбранного дня.

Это согласованное направление макета; календарный День принят в bounded scope, остальные режимы ещё не реализованы. Реальное поведение/жесты/переносы/Dynamic Type и устройство проверяются при исполнении будущих маленьких TASK. Одобрение концепта не означает GUI/device PASS или приёмку NATIVE-002 вне его Inbox scope.

## NATIVE-005: маленький редактор интервала

Clock-action у датированной строки открывает native sheet с «Начало» HH:mm и «Длительность, мин», явными Save/Cancel/Clear. Системные формы/цвета, прежний coral accent, доступные подписи и >=44pt actions; keyboard/Dynamic Type не скрывают controls. Текстовый ввод временно даёт простой проверяемый editor без calendar wheel/UTC конверсий. Строка показывает start–derived end и (+1 день), когда end на следующую дату. Дизайн главной навигации/календаря в этом задании не реализуется.

## NATIVE-006: только list «Сегодня»

Две настоящие системные вкладки Сегодня/Входящие, общий coral accent. Today показывает local date и open/completed строки текущей plannedDate; existing date/time controls и empty state/action в Inbox. Нет фиктивного «Расписания», календарных вкладок или Glass imitation. Сетка Дня — следующий маленький TASK.

## Исторический NATIVE-007B: первый календарный renderer Дня

Третья настоящая вкладка Календарь, выбранная civil дата, Prev/Next/Сегодня/picker. Один полный Day timeline00–24, untimed отдельно, overlaps side-by-side, muted completed и positive overnight cues. Системные native controls/materials, общий coral accent.3days/Month/Projects без готовой реализации не добавлять как пустые selectors. Existing editor по tap;drag/new creation не входят.

## Уточнения пользователя 2026-10-14

«Без времени» — раскрываемая область над временной сеткой: default до3tasks + «ЕщёN», expanded максимум примерно треть полезного экрана, internal scroll при избытке, grid position сохраняется. В будущем3days задачи под своим днём при общей высоте верхней области;007C реализует только Day.

Следующие отдельные gestures: перенос задачи из untimed в calendar, resize краёв интервала, плавное раздвижение overlaps. Preview/time hint/snap/haptic — уточнить в соответствующих TASK; изменения сохраняются после отпускания, промежуточный drag не является записью. Не входят в007C.

Пустой Today позже: небольшая коралловая точка на тонкой орбите, «Сегодня свободно», «Можно выдохнуть — или запланировать что-нибудь.», действие «Открыть Входящие» до появления настоящего quick-add на Today; русский формат даты. Это согласованный дизайн, пока не implemented.

### Компактный верх календаря — прямое уточнение 2026-10-14

Убрать large title «Календарь» и лишний верхний title gap: сразу компактная дата/navigation под native safe area. Untimed — маленькие тонированные capsules с completion circle+однострочным title, без повторной даты и видимых clock/calendar actions в каждой строке. Full title/edit actions доступны через existing sheet/native menu. Interaction targets >=44pt при компактном paint, accessibility sizes адаптируются. Большие строки остаются обычным list Today/Inbox. Это новый scope007C-R2; адаптивное раскрытие/internal scroll сохраняются, gesture/calendar modes сюда не входят.

## Навигация2026-10-14 — обязательное уточнение пользователя

Сегодня: same-local-day Список/Календарь; Предстоящее: Список/Календарь с выбранной датой/диапазоном, modes меняют представление same source UUID, не создают копии. Старые screenshot tabs не целевое product поведение. 3days/Month не реализовывать вместе с перестройкой navigation.
