# Orbit — активный native дизайн

2026-10-12: SwiftUI iOS/macOS, русский интерфейс. Прежний веб-дизайн docs/web-baseline-2026-10-12/DESIGN.md сохранён как reference, не шаблон обязательного пиксельного переноса.

## Первый экран

Inbox: заголовок «Входящие», короткое поле «Название задачи» и действие «Добавить», Enter добавляет. Пустой state честный, без seed данных по умолчанию. Строка: текст + независимый control завершения; завершённые задачи доступны для reopen. Обе группы можно показать простыми секциями, без панели фильтров в первом TASK. После save input очищается, после failure draft остаётся и ошибка видна. SwiftUI native controls, Dynamic Type/accessibility labels, клавиатура и системная тема.

На Mac — нормальное окно с рабочим клавиатурным вводом; не строить сразу большой sidebar из пустых маршрутов. На iPhone позже — компактный native список с safe areas; адаптация target/nav отдельная задача. Никаких экранов логина, предупреждений о сервере или фальшивых счётчиков/синхронизации.

Следующие screens только по отдельным assignments: Projects, Today/Upcoming, task editing. Не переносить технические storage/sync подробности в основной пользовательский flow; ошибка сохранения должна быть понятной и не скрывать потерю записи.

## Актуальное направление iPhone, 2026-10-13

Пользователю нравится визуальный стиль интерактивного концепта: системная типографика, спокойные поверхности, тонкие разделители, круглое завершение, один coral accent; нативный Liquid Glass для нижней навигации и действия добавления при поддержке системой. Следующие задания должны сохранять это направление, а не повторять примитивный macOS prototype UI.

Нижние вкладки: Сегодня · Входящие · Календарь · Проекты. Сегодня: Список/Расписание. Календарь: День/3 дня/Месяц. Неделя удалена по прямому запросу. 3 дня строятся точно по принципу Дня: три полных временных колонки с общей шкалой, блоки задач в своих интервалах и отдельная область для задач без времени. Полный диапазон суток должен быть доступен в настоящем приложении;9–20 в макете — демонстрационный диапазон, не ограничение модели задач. Месяц — сетка дат и задачи выбранного дня.

Это согласованное направление макета; календарь пока не реализован в SwiftUI. Реальное поведение/жесты/переносы/Dynamic Type и устройство проверяются при исполнении будущих маленьких TASK. Одобрение концепта не означает GUI/device PASS или приёмку NATIVE-002 вне его Inbox scope.
